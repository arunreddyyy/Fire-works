Interactive Visual Art

Description

This project is a creative visual experience built using HTML, CSS, and JavaScript. It uses animations and interactive effects to create an attractive background for websites.

Features

- Interactive visual effects
- Smooth animations
- Simple and clean design
- Responsive layout
- Built using basic web technologies

Technologies Used

- HTML5
- CSS3
- JavaScript

Getting Started

1. Clone the repository:
   
   git clone https://github.com/arunreddyyy/Fire-works.git

2. Open the project folder in VS Code.

3. Open "index.html" in your browser.

No additional installation is required.

Project Objective

The goal of this project is to explore creative web design and learn how HTML, CSS, and JavaScript can be used to create interactive visual effects.
