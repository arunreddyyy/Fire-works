Interactive Visual Art

Description

This is a fun and creative project made with HTML, CSS, and JavaScript. It creates beautiful moving animations and interactive effects that you can use as a cool background for any website.

Features

  Interactive visual effects
  Smooth animations
  Simple and clean design
 
Technologies Used

HTML5
CSS3
JavaScript

Getting Started

1. Clone the repository:
   
   git clone https://github.com/arunreddyyy/Fire-works.git

2. Open the project folder in VS Code.

3. Open "index.html" in your browser.

    "OR"
   Run it through the deployed link
   https://arunreddyyy.github.io/Fire-works/

Project Objective

The goal of this project is to explore creative web design and learn how to use HTML, CSS, and JavaScript together to build fun, moving visual effects.

Created using HTML, CSS, and JavaScript.
